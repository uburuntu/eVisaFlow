## Contributing

Thanks for your interest in improving evisa-flow.

## Guidelines

- Use sample data only; do not include personal or credentialed data.
- Run `corepack enable` once, then use `pnpm install`.
- Run `make validate` before submitting.
- Use `pnpm up --latest -r` for dependency refreshes; the workspace enforces a
  3-day minimum package release age.
- Keep changes focused and describe the why in your PR.
